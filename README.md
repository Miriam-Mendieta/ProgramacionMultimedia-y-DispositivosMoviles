¡Bienvenid@ a mi espacio de trabajo donde recopilo Proyectos, prácticas y apuntes del módulo de Programación Multimedia y Dispositivos Móviles.

---
## 📝 Contenido
- 🟥 **01. Introducción a Kotlin**
- 🟧 **02.**[Introducción a Android y componentes de Jetpack:](https://github.com/Miriam-Mendieta/ProgramacionMultimedia-y-DispositivosMoviles/tree/main/ConvertidorDecimal_Binario_Hexadecimal) primeros pasos en el entorno de Android Studio con los componentes   esenciales de **Jetpack**.
- 🟨 **03. Componentes de Jetpack Compose:** Diseño de interfaces de usuario modernas, declarativas y reactivas utilizando *composables* (Text, Button, Row, Column, LazyColumn, etc.).
- 🟩 **04.** [Temas y Navegación:](https://github.com/Miriam-Mendieta/ProgramacionMultimedia-y-DispositivosMoviles/tree/main/ProfileYou) Gestión de estados visuales, personalización de temas (Light/Dark mode) y estructuración del flujo de la app mediante **Compose Navigation**.
- 🟦 **05. Corrutinas y Efectos Laterales**
- 🟪 **06. Persistencia de Datos**
- 🟫 **07. Utilizando APIs:** Conexión con servicios web externos, consumo de APIs REST.
- 🟩 **08. Firebase:** Integración de herramientas en la nube, incluyendo autenticación de usuarios, base de datos en tiempo real (**Firestore**) y almacenamiento de archivos.
- 🟥 **09. Introducción a los Videojuegos:** Conceptos teóricos clave, ciclo de vida del juego (*Game Loop*), físicas básicas y renderizado de gráficos.
- 🟧 **10. Introducción a Unity:** Configuración del entorno de trabajo, gestión de la interfaz de Unity, creación de escenas y uso del sistema de Assets.
- 🟨 **11. Controlando Unity:** Creación de mecánicas de juego interactivas, scripts en **C#**, gestión de inputs, colisiones y control de animaciones.

---

## 🛠️ Tecnologías y Herramientas

*   **Lenguajes:** [Kotlin](https://kotlinlang.org/) (Android) y [C#](https://learn.microsoft.com/en-us/dotnet/csharp/) (Unity).
*   **Entornos de Desarrollo:** Android Studio & Unity Editor.
*   **UI Framework:** Jetpack Compose.
*   **Backend & Cloud:** Firebase Console.

---
## 🚀 Cómo Empezar

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   ```
2. **Para proyectos Android:** Abre la carpeta correspondiente para *Android Studio* y sincroniza los archivos de Gradle.
3. **Para proyectos de Unity:** Añade la carpeta del proyecto que necesites.
